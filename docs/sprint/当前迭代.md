### 上下文增强详情

**repo_map 项目结构地图**（`backend/workflow/repo_map.py`）：
- 深度扫描工作目录（4 层），提取函数/类签名（AST for Python, regex for JS/TS/Go/Rust/Java）
- token 预算控制（~2000 token / 6000 chars）
- 首次调用 `run_workflow_agent` 时懒构建，缓存到 `session.repo_map`
- 所有工作流阶段的 system prompt 均注入 repo_map

**阶段间上下文传递**（`backend/prompt_builder.py` + `backend/workflow/engine.py`）：
- planner 方案概述 + 风险 → 注入 coder 和 reviewer 的 system prompt
- 已完成任务清单 → 注入 coder、reviewer、feedback 阶段的 system prompt
- 当前任务上下文（标题/描述/验收标准）→ 注入 reviewer 的 system prompt 和 user message
- coder 的 user message 也包含方案概述和已完成任务，强化上下文感知
