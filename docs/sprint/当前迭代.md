### 上下文增强详情

**repo_map 项目结构地图**（`backend/workflow/repo_map.py`）：
- 深度扫描工作目录（4 层），提取函数/类签名（AST for Python, regex for JS/TS/Go/Rust/Java）
- token 预算控制（~2000 token / 6000 chars）
- 首次调用 `run_workflow_agent` 时懒构建，缓存到 `session.repo_map`
- 所有工作流阶段的 system prompt 均注入 repo_map

**阶段间上下文传递**（`backend/prompt_builder.py` + `backend/workflow/engine.py`）：
- planner 方案概述 + 风险 → 注入 coder 和 reviewer 的 system prompt
- 已完成任务清单 → 注入 coder、reviewer、feedback 阶段的 system prompt
- 当前任务上下文（标题/描述/验收标准）→ 注入 reviewer 的 system prompt 和 user message
- coder 的 user message 也包含方案概述和已完成任务，强化上下文感知

### CLI 体验打磨详情

**彩色输出系统**（`backend/cli_display.py`）：
- ANSI 颜色码 + Windows VT100 自动启用 + TTY 检测降级
- 角色配色（planner 蓝 / coder 绿 / reviewer 黄）和阶段配色
- 进度条、阶段横幅、审查结果格式化、Token 使用统计
- `--no-color` 参数支持

**Spinner 动画**（`backend/cli_display.py`）：
- agent 思考时显示旋转动画（后台线程，0.08s/帧）
- 非 TTY 环境静默无操作
- 阶段切换/工具调用/文本输出时自动停止

**实时 Diff 展示**（`backend/cli.py` + `backend/orchestrator.py`）：
- coder 产出文件变更后，orchestrator 广播 `files.changed` 事件
- CLI 接收后彩色渲染 unified diff（增行绿/删行红/文件头青/hunk 头洋红）
- 超过 50 行自动截断
- 文件变更摘要行（✦ 新建 / ✎ 修改 / ✗ 删除）

**CLI 增强功能**（`backend/cli.py`）：
- `--verbose/-v` 调试日志、`--version` 版本号
- 用法示例、Ctrl+C 优雅退出（exit code 130）
- 会话列表按最近活跃排序、编号 + 总数
- 工具调用序号（#1, #2, ...）、阶段耗时统计、完成摘要（文件变更数/跳过任务数/逐任务状态 ✓/-/○）

### `/undo` 撤销命令详情

**undo 命令**（`backend/workflow/engine.py`）：
- 在 CODE_REVIEW / FEEDBACK 阶段可用
- 弹出最后一个已完成任务，回退任务索引
- 重置任务状态为 pending、清空 diff/review/retry_count/guidance_queue
- CLI 中按 `u` 触发

**files.changed 广播**（`backend/orchestrator.py`）：
- `run_workflow_agent` 中 staging.commit() 后检测文件变更
- 有变更时广播 `files.changed` 事件（含 path/action/diff_text/combined_diff）
- 无变更时不广播

**FEEDBACK 循环重试上限**（`backend/workflow/engine.py`）：
- 每个子任务最多重试 3 次（`MAX_RETRIES_PER_TASK = 3`）
- 达到上限后自动跳过当前任务，推进到下一个
- `WorkflowState.retry_count` 持久化，恢复后保持计数
- `_advance_to_next_task` 重置 retry_count

**任务索引感知**（`engine.py` 广播 + 消息构建）：
- coder 广播 detail 包含 "任务 1/5: xxx" 格式
- 重试时广播包含 "（重试第 N 次）"
- `_build_coder_message` 包含 "（任务 2/5）" 前缀
- FEEDBACK 暂停提示显示当前重试次数

**CLI 耗时统计**（`backend/cli.py`）：
- 每个阶段切换时显示上一阶段耗时
- agent 完成时显示该 agent 耗时
- 工具调用显示序号（#1, #2, ...）
- 完成摘要包含文件变更数、跳过任务数、逐任务状态明细
